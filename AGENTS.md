# AGENTS.md — working on Sudoku Belts

Sudoku Belts teaches Sudoku techniques on real puzzles. It is a static web app (PWA) with no build step and no runtime dependencies.

- Live: https://sudoku-dojo-eight.vercel.app (landing) · `/app/` (the app)
- **Task board: [`TASKS.md`](TASKS.md). Read it first. Update it in the same commit as your work.**
- Research behind the roadmap: [`research/`](research/)

## Map

```
index.html              Landing page (self-contained CSS)
app/                    The app; all paths inside are relative (served at /app/)
  js/engine.js          Geometry (9×9, 6×6), solver, generator, technique finders.
                        THE single source of truth for technique logic AND step explanations.
  js/lessons.js         Lesson copy, belts, tiers (plain-language text only)
  js/habit.js           Pure functions for practice days, streak, weekly view, review queue
  js/board.js           Board renderer + highlight levels
  js/app.js             Screens, routing (#/learn, #/lesson/x, #/play, #/game, #/gym, #/rush, #/daily, #/me), storage
  js/fx.js              Sound, haptics, confetti
  data/bank.js          GENERATED by tools/build-bank.js — never hand-edit
  sw.js                 Offline cache (network-first). Bump CACHE when the shell file list changes.
tools/build-bank.js     Generates + verifies the bank (deterministic seed)
tools/check.js          Node checks: engine on every bank position + habit logic
research/               Research reports (input to TASKS.md)
assets/                 Real screenshots used by README and landing page
```

## Commands

```bash
python3 -m http.server 5178    # serve; open http://localhost:5178/app/
npm run bank                   # regenerate + verify app/data/bank.js
npm test                       # node tools/check.js
```

## Rules

1. **Correctness first.** Any change to a technique finder must keep `npm run bank` and `npm test` green. The bank build fails if any step places a wrong digit or removes a true candidate.
2. **Explanations come from the engine.** A step's `hint` and `text` must be true for that exact position. Don't claim "the placed digits rule out every cell" unless they really do.
3. **No build, no framework, no dependencies.** ES modules, relative paths, works from `/app/`.
4. **Local-only data.** Progress lives in `localStorage` key `sudoku-dojo-v1`. Add new fields with defaults in `fresh()` and migrate old shapes in `load()`; never break an existing save.
5. **Plain language for players.** Short words, define a term the first time (e.g. "notes = small digits showing what could still fit"). No jargon without explanation.
6. **Don't punish asking for help.** Hints never cost stars; guided vs solo is shown separately.
7. **Verify in a real browser** (phone width 390×844, light and dark) before saying a UI change works. Screenshot it.

## Shipping

- `main` auto-deploys to Vercel production. Push only working, tested code.
- Commit messages: what changed for the player, then details.
- After shipping: move items to ✅ in `TASKS.md` with the release name and date.
